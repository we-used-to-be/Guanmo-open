>
> 本手册面向使用软件的用户，也可作为 AI 解答观墨操作问题的资料。正文不依赖截图，入口名称按当前界面描述。安装包或在线体验页可能与仓库版本不同，遇到差异请先查看软件版本。

> 核对范围：当前源码、界面文案与功能契约。本次文档编写未逐项进行桌面或浏览器实机验收；阅读提醒的系统通知尤其需要在实际设备上验证。

### 1.2 操作记法与术语

- **设置 → 编辑器 → 自动保存**：先打开设置，选择“编辑器”页，再找到“自动保存”开关。
- **右键标签 → 另存为**：在顶部文档标签上点击鼠标右键，选择“另存为”。
- **Ctrl + S**：同时按下 Ctrl 和 S。本文快捷键以 Windows 为准。
- 图标没有文字时，将鼠标停留在图标上查看提示名称，再按本文描述操作。

| 术语 | 含义 |
| --- | --- |
| 文档／原文 | 你打开或新建的 Markdown 内容；保存后对应本地 .md 文件 |
| 标签页 | 顶部一个已打开文档的入口，可以切换、关闭或固定 |
| 工作区 | 你主动打开的本地文件夹，可以同时添加多个 |
| 上下文标签 | AI 输入框中的选区或文件标签，用来说明本轮问题的资料和目标 |
| 高亮／文字批注 | 你在预览原文上保存的人工阅读记录 |
| AI 阅读成果 | 明确保存的 AI 摘要、问题集、AI 解读或阅读笔记 |
| 知识库 | 已加入索引的本地 Markdown 文档，用于跨文档检索 |
| Embedding | 把文本转换为向量的模型服务，主要用于知识库语义检索 |
| 长期记忆 | 经确认保存的偏好、事实和约定，独立于文档和聊天记录 |
| Agent | AI 根据任务读取资料、检索或提出操作的执行流程；是否实际执行取决于权限与确认 |

### 1.3 桌面版与网页版

观墨以 Markdown 阅读、编辑和 AI 辅助理解为主要用途。桌面版提供完整的本地数据能力；网页版使用相似界面，但有明确限制。

| 能力 | Windows 桌面版 | 网页版 |
| --- | --- | --- |
| Markdown 编辑、预览、分屏、对照、Diff | 支持 | 支持 |
| 打开单个 .md 文件 | 支持 | 支持，使用浏览器文件选择 |
| 目录工作区、原位保存 | 支持 | 取决于浏览器的目录／文件授权能力 |
| 自动保存 | 支持，已有保存路径的文档可用 | 不提供自动保存 |
| 双击文件唤起应用、打开文件位置 | 支持系统集成 | 不提供桌面系统集成 |
| 文件、标签页和会话跨重启／刷新恢复 | 支持桌面会话恢复 | 文件、标签页和聊天不会跨刷新恢复 |
| 基础 AI 对话、联网搜索 | 支持 | 支持，受浏览器跨域策略限制 |
| 高亮、批注、阅读成果及收藏分类 | 支持 | 不提供持久化阅读成果 |
| 知识库、Embedding、长期记忆 | 支持 | 不提供 |
| 持久聊天历史、数据库备份 | 支持 | 不提供 |
| 官方／本地全屏背景库 | 支持 | 不提供桌面背景库 |
| 使用时长统计、更新检查、诊断日志 | 支持 | 不提供桌面服务 |
| API Key 保存 | Windows 系统加密保存 | 页面内存、风险确认后的明文保存或密码加密保存 |

网页版目录功能推荐在支持 File System Access API 的 Chrome 或 Edge 中使用，并以当前浏览器是否开放该能力为准。其他浏览器仍可选择单个文件并下载保存。不要把“已在网页中编辑”当作“已写回原文件”；具体保存方式见[网页版保存](#web-save)。

## 2. 快速开始

### 2.1 安装与启动

1. 打开 [GitHub Releases 下载页](https://github.com/we-used-to-be/Guanmo-open/releases)，选择所需版本的 Windows 安装包。
2. 完成安装，启动观墨。
3. 在“设置 → 通用 → 关于”查看当前版本。使用其他版本时，按钮或功能可能与本手册不同。
4. 如果只想体验，可打开[网页版](https://we-used-to-be.github.io/Guanmo-page/)；线上部署版本不一定与仓库同步。

当前主要交付 Windows 桌面版。其他操作系统的安装包以下载页实际提供的产物为准。

要用观墨双击打开 Markdown，可在 Windows 文件管理器中右键 .md 文件，选择“打开方式”，指定观墨并按系统选项设为默认应用。文件关联正常时，双击文件会启动或唤回观墨。

### 2.2 打开、阅读并保存第一篇文档

1. 点击左侧“打开文件”图标，或按 **Ctrl + O**。
2. 选择一个 .md 文件。支持大小写不同的 .md 扩展名；其他文档格式不能作为 Markdown 标签打开。
3. 点击顶部“预览模式”，或按 **Ctrl + Shift + 2**，阅读排版后的内容。
4. 点击“编辑模式”，或按 **Ctrl + Shift + 1**，修改 Markdown 源码。
5. 按 **Ctrl + S** 保存。新建文档第一次保存时需要选择位置和文件名。
6. 确认标签页的修改标记和底部“已修改”状态已消失；出现保存失败提示时，先处理失败再关闭文档。

桌面文档打开上限为 **1 MiB（1,048,576 字节）**，按 UTF-8 文件字节数计算，等于上限可以打开。超过上限请先拆分文件；不要只按字数估算大小。

### 2.3 新建自己的文档

1. 按 **Ctrl + N**，或点击普通标签栏右侧的“+”。
2. 切换到编辑模式，输入以下 Markdown：

~~~markdown
# 我的阅读笔记

## 核心观点

- 第一条观点
- 第二条观点

## 待办

- [ ] 补充资料
- [ ] 整理结论
~~~

3. 按 **Ctrl + S**，保存为 .md 文件。
4. 切换到预览，查看标题、列表和任务项的排版。

**先保存，再插入本地图片。** 图片需要存放在 Markdown 所在目录的资源文件夹中。

### 2.4 第一次使用 AI

1. 按 **Ctrl + I** 打开设置，进入“AI 模型”。
2. 在“对话 API 配置”选择服务预设，或填写 API Base URL、API Key 和对话模型。
3. 先发送一个不依赖文档的问题，例如“用两句话解释 Markdown”。
4. 要提问原文，选中文字，右键选择“添加到 AI 上下文”，确认输入框出现选区标签后发送问题。
5. 要保存有用回答，将鼠标移到 AI 回复附近，打开“保存回复”，选择成果类型或 Markdown。

模型配置、文件修改与数据发送边界见[AI 助手](#ai)。对话模型与 Embedding 模型是两套配置，基础聊天不要求先配置 Embedding。

## 3. 界面与操作入口

### 3.1 主界面

| 区域 | 主要用途 | 常用入口 |
| --- | --- | --- |
| 左侧侧栏 | 打开文件、搜索、最近文件、收藏、工作区 | 打开文件、打开文件夹、设置；Ctrl + B 展开／收起 |
| 顶部标签栏 | 切换文档、查看修改状态、收藏和标签右键操作 | 点击标签、右键标签、“+” |
| 顶部模式区 | 选择编辑和阅读方式、导出文档 | 编辑、预览、编辑+预览、对照、Diff、导出 |
| 中央工作区 | 编辑源码、阅读排版内容、比较文档 | 目录、搜索、选区右键、预览内编辑 |
| 底部状态栏 | 查看文档状态、打开 AI 或阅读成果 | 右下角“AI”和阅读成果图标 |
| 右侧面板 | AI 对话、历史记录、阅读成果、阅读提醒 | 面板顶部切换入口和关闭按钮 |

左侧收起时仍保留一列常用图标。展开后可查看文件分组；拖动侧栏边缘可调整宽度。AI 面板与文档工作区可按需显示，不需要一直保持打开。

### 3.2 设置、命令面板和快速打开

- **设置**：点击左侧设置图标，或按 Ctrl + I。
- **命令面板**：按 Ctrl + Shift + P，输入操作名称，用上下方向键选择并按 Enter 执行；Esc 关闭。
- **快速打开**：按 Ctrl + P，按名称查找当前标签页或最近文件。它不是全文检索，也不是扫描电脑全部文件。
- **搜索当前文档**：按 Ctrl + F，或点击侧栏“搜索”。

### 3.3 重新查看产品导览

“设置 → 通用”提供产品导览入口，可以重新查看总览或主题导览，包括文件与阅读、全屏模式、批注与阅读成果、AI 助手、主题与个性设置。

交互导览用于认识界面；本手册用于查阅完整步骤和限制。导览中的批注示意不会作为真实批注写入你的文件或数据库。

## 4. 文件、工作区与标签页

### 4.1 打开方式和文件授权

桌面版可以通过以下方式打开 Markdown：

- 左侧“打开文件”或 Ctrl + O。
- 打开文件夹后，从工作区树点击文件。
- 从最近文件、收藏或快速打开列表选择文件。
- 将 .md 文件拖入窗口。
- 在 Windows 中双击已关联的 .md 文件。

打开工作区表示授权观墨访问该目录；打开单个文件表示授权该文件。单独打开文件不会把整个父目录变成工作区。

如果旧记录指向的文件无法访问，先确认文件仍存在，再通过“打开文件”或“打开文件夹”重新选择原路径。移动文件后，旧最近记录、来源定位或历史授权不一定能自动找到新位置。

### 4.2 添加和关闭工作区

1. 点击左侧“打开文件夹”。
2. 在系统选择器中选择需要管理的目录。
3. 在“工作区”分组展开目录，点击 Markdown 文件打开。
4. 可以重复添加其他文件夹，各工作区独立显示。
5. 要移除侧栏中的工作区，在工作区根节点右键选择“关闭工作区”。

**关闭工作区只移除工作区入口，不删除磁盘文件。**

在工作区根节点右键可选择“新建文件”或“新建文件夹”。输入名称后按 Enter；新建文档使用 .md 扩展名。已有文件或文件夹可通过对应右键菜单重命名；这会修改实际磁盘名称。

### 4.3 保存、自动保存和另存为

| 操作 | 入口与结果 |
| --- | --- |
| 保存 | Ctrl + S；已有路径写回该文件，新文档先选择路径 |
| 自动保存 | 设置 → 编辑器 → 自动保存；桌面已有路径的文档修改后自动写回 |
| 另存为 | 标签或文件右键 → 另存为；选择新路径保存副本，注意是否覆盖已有文件 |
| 打开文件位置 | 桌面标签或文件右键 → 打开文件位置；在 Windows 资源管理器中定位文件 |
| 复制路径 | 标签右键 → 复制路径；复制文件地址，分享前注意其中可能包含私人目录信息 |

新建但未选择保存位置的文档不会凭空创建磁盘文件。自动保存失败时会提示，不能仅凭已开启自动保存判断数据已经落盘。

关闭标签、批量关闭标签或退出软件前，先保存需要保留的改动。不要依赖关闭操作一定弹出保存询问；桌面会话恢复也不能替代手动保存或备份。

### 4.4 最近文件和文件收藏

- **最近文件**记录近期打开的文档，点击可再次打开。
- 最近列表中的“删除最近记录”仅移除记录，不删除磁盘原文。
- 鼠标移到已保存文档的标签上，点击星形按钮可收藏；再次点击可取消。
- **文件收藏**保存的是常用文档入口，不会复制一份文档。
- 文件移动或删除后，收藏入口可能失效；重新打开新位置，再调整收藏。

文件收藏与[阅读成果收藏](#artifact-organization)相互独立：前者收藏整篇文档入口，后者收藏某条高亮、批注或 AI 成果。

### 4.5 多标签页操作

点击标签切换文档。右键标签可使用：

- 固定／取消固定。
- 在右栏打开，用于双文档对照。
- 重命名、另存为。
- AI 总结该文件、添加文件到 AI 上下文。
- 桌面知识库的加入或更新操作。
- 关闭、关闭其他、关闭右侧标签、全部关闭。

关闭标签不会删除磁盘文件。批量关闭前先保存所有需要保留的修改。

桌面版启动时会尝试恢复上次会话。文件被移动、权限失效或磁盘不可用时，部分标签可能无法恢复；重新选择文件即可继续使用。网页版刷新后不恢复这些状态。

<a id="web-save"></a>

### 4.6 网页版打开与保存

网页版没有桌面自动保存，请主动按 Ctrl + S：

1. 支持文件／目录授权的浏览器会请求访问权限。
2. 已取得可写句柄的文档可写回原文件。
3. 无法原位写入时，保存会下载一份 .md 文件，由你选择是否替换原文件。
4. 浏览器下载成功不等于原文件已被替换，请检查实际保存位置。
5. 刷新或关闭页面前，保存所有改动和需要保留的 AI 回复。

网页版文件、目录、标签和聊天仅在本页会话中存在。API Key 的保存方式另见[网页密钥](#web-keys)，保存密钥不会保存文档或聊天。

## 5. 编辑、阅读与比较

### 5.1 选择合适的模式

| 模式 | 显示内容 | 适合的任务 |
| --- | --- | --- |
| 编辑 | Markdown 源码 | 写作、调整语法和结构 |
| 预览 | 排版后的正文 | 阅读、选区提问、高亮批注 |
| 编辑+预览／分屏 | 同一文档的源码与预览 | 一边写作一边检查排版 |
| 对照阅读 | 左右两栏文档预览 | 同时阅读两份资料 |
| Diff | 打开时的内容与当前内容的差异 | 检查本次编辑改了什么 |

普通模式在顶部模式区切换，全屏在顶部控制条切换。切换模式本身不会重写正文；已经进行的编辑仍需按保存规则处理。

### 5.2 编辑与 Markdown 右键菜单

在编辑模式中输入源码。选中文字后右键，可使用复制、添加到 AI 上下文、快捷 AI，以及加粗、斜体、行内代码、代码块、引用、链接等操作。

在编辑器空白处右键，可插入标题、引用、代码块、链接、表格、任务列表和分割线。

这些格式操作直接改变 Markdown 内容；AI 快捷操作是否立即发送由“设置 → 编辑器 → 快捷 AI 自动发送”控制。不要把加粗等格式按钮与 AI 修改确认流程混为一谈。

<a id="inline-edit"></a>

### 5.3 在预览里编辑源码

**入口：设置 → 编辑器 → 预览内源码编辑；预览中按 Alt + 鼠标左键。**

1. 确认“预览内源码编辑”已开启。
2. 在预览中按住 Alt，点击要修改的 Markdown 块。
3. 该位置出现局部源码编辑器，修改对应段落、列表或其他块。
4. 点击编辑块外的普通区域，提交修改并返回预览；也可用 Ctrl + S 提交并保存。
5. 确认预览变化和文档保存状态。

这是编辑该块源码，并非只跳转到另一侧编辑器。Enter 用于编辑内容，不是统一的提交快捷键。

如果出现“内容已在其他位置发生变化，修改尚未覆盖原文”，说明编辑期间对应原文发生变化。先用“复制修改内容”保留草稿，再核对当前文档；不要把冲突提示当作已经保存。

### 5.4 目录与阅读位置

目录由文档中的 Markdown 标题生成。展开目录并点击标题可定位对应章节。没有标题的文档可能没有可用目录项。

对照模式的目录区分左右文档，使用对应目录导航。桌面文档切换、视图切换和会话恢复会尝试保留阅读位置；正文大幅改动后，位置可能调整。

### 5.5 分屏与同步滚动

1. 选择“编辑+预览”，或按 Ctrl + Shift + 3。
2. 在左侧编辑源码，右侧查看排版。
3. 在“设置 → 编辑器 → 同步滚动”开启或关闭两侧联动。
4. 开启时滚动一侧，另一侧尽量定位到对应内容。

源码行高与排版高度不同，图片、公式或图表也可能改变高度，因此两侧滚动条百分比不必相同。对照阅读两篇不同文档时，也不应按同一篇文档的对应行关系理解。

### 5.6 双文档对照

1. 打开需要比较的两篇 Markdown。
2. 将主文档设为当前标签，选择“对照阅读”或按 Ctrl + Shift + 4。
3. 在另一篇文档的标签上右键，选择“在右栏打开”。
4. 分别滚动和阅读两栏，使用各自目录导航。

对照阅读用于并排查看两份资料。想查看当前文档本次编辑的增删，使用下一节的 Diff。

### 5.7 Diff 对比

选择“Diff”，或按 Ctrl + Shift + 5。

Diff 比较**该文档打开时的内容快照**与**当前标签内容**，标出增加、删除和未变部分。自动保存不会把比较基线改成“刚保存的版本”。

因此，保存后仍看到差异属于正常情况。Diff 不是 Git 历史、任意两个磁盘文件比较或无限版本记录；需要对照两份文件时使用双文档对照。

### 5.8 搜索与替换

**入口：Ctrl + F，或左侧“搜索”。**

1. 输入关键词，查看匹配数量和高亮。
2. 在搜索输入框按 Enter 查找下一处，Shift + Enter 查找上一处，也可点击上下箭头。
3. 展开替换区域，输入替换文字。
4. “替换”处理当前匹配；“全部替换”处理所有匹配。
5. 替换后检查正文并保存，需要撤销时在编辑器使用撤销操作。

搜索针对当前文档；在双文档模式操作前先确认搜索目标。它不是工作区全文搜索，也不同于 AI 知识库检索。预览里的高亮是搜索结果显示，不会自动成为保存的阅读高亮。

## 6. Markdown 内容、图片与导出

### 6.1 常用 Markdown 写法

| 内容 | 示例 |
| --- | --- |
| 一级／二级标题 | `# 标题` ／ `## 小节` |
| 加粗／斜体 | `**加粗内容**` ／ `*斜体内容*` |
| 无序／有序列表 | `- 项目` ／ `1. 项目` |
| 任务列表 | `- [ ] 未完成` ／ `- [x] 已完成` |
| 引用 | `> 引用内容` |
| 链接 | `[文字](https://example.com)` |
| 图片 | `![描述](./assets/image.png)` |

代码块使用三个反引号包围，可在开头标注语言，如 javascript、python。表格使用竖线分隔单元格，并用分隔行定义表头。

观墨支持 GFM、代码高亮、表格、任务列表、数学公式、Mermaid、ECharts 和经过安全处理的 HTML。任务列表在可编辑预览中点击勾选会改变对应 Markdown，请按文档保存规则处理。

### 6.2 插入本地图片

**桌面入口：编辑区“选择图片插入”按钮、拖入图片、粘贴剪贴板图片。**

1. 先将当前文档保存为 .md 文件。
2. 把编辑光标放到插入位置。
3. 点击“选择图片插入”选择图片，或将图片拖入编辑区，或粘贴图片。
4. 软件把图片保存到文档同级的 assets 资源目录，并插入相对路径。
5. 切换预览检查显示效果，再保存 Markdown。

图片是单独的文件。迁移或分享文档时，需要同时带上对应 assets 目录，保留相对路径关系。只复制 .md 可能导致图片失效。

手工填写远程图片地址时，显示受网络与地址可用性影响。网页版不提供相同的桌面资源写入流程；可以手工填写图片链接，本地资源是否可读取决于浏览器授权。

### 6.3 公式、Mermaid 和 ECharts

行内公式使用美元符号包围，如 $E=mc^2$；独立公式使用双美元符号：

~~~markdown
$$
E = mc^2
$$
~~~

Mermaid 使用标记为 mermaid 的代码块：

~~~mermaid
flowchart LR
  A[阅读] --> B[批注]
  B --> C[整理成果]
~~~

ECharts 使用标记为 echarts 的代码块，内容必须是 JSON 配置：

~~~echarts
{
  "xAxis": { "type": "category", "data": ["周一", "周二", "周三"] },
  "yAxis": { "type": "value" },
  "series": [{ "type": "bar", "data": [2, 4, 3] }]
}
~~~

图表不执行文档提供的任意 JavaScript。函数表达式、危险资源地址或不支持的交互配置可能被拒绝；出现图表错误时先检查代码块语言、JSON 格式和配置。

HTML 和 SVG 会经过安全处理。脚本、事件处理器等内容可能被移除，不能按普通网页执行代码的方式使用 Markdown 预览。

### 6.4 导出 HTML

1. 在顶部选择“导出 → 导出 HTML”，或按 Ctrl + Shift + E。
2. 桌面版选择 .html 或 .htm 文件保存位置；网页版按浏览器保存方式下载。
3. 打开导出文件检查正文、图片、公式与图表。

导出使用当前标签内容，包括尚未写回磁盘的编辑。导出不能替代保存 Markdown，也不会把阅读成果数据库作为文档附件打包。

桌面 HTML 导出会尝试嵌入本地图片；若提示本地图片无法读取，修复路径和授权后再导出。不要把 HTML 保存到原 .md 文件上。

### 6.5 导出 PDF

1. 在顶部选择“导出 → 导出 PDF”。
2. 等待图片、字体、公式与图表准备完成。
3. 在打开的打印对话框中选择“另存为 PDF”或系统 PDF 打印机。
4. 按需要设置纸张、边距和缩放，保存后检查分页。

出现“已打开 PDF 打印对话框”仅表示进入打印步骤，仍需在系统对话框完成保存。图片、字体或图表未准备完成时可能取消导出；先确保预览内容正常，再重试。

### 7.2 切换文件和使用 AI 小窗

### 7.3 正文边距和主题

## 8. 高亮、批注与阅读成果

**适用环境：桌面版，数据库就绪。人工标记需要已保存到本地路径的 Markdown。**

### 8.1 添加高亮

1. 打开已保存的 .md 文件，进入预览；普通预览、全屏预览和双文档预览均有对应阅读操作。
2. 拖选需要记录的文字。
3. 点击选区附近的“添加批注”入口，展开工具栏。
4. 选择黄色、绿色、蓝色或粉色，保存高亮。
5. 点击已有高亮可再次打开管理工具。

高亮保存在应用数据库中，**不会把颜色标签写进 Markdown 正文**。清除临时选区不会删除已保存高亮。

公式、图表等特殊渲染区域的选区可能不能像普通文字一样精确定位。需要稳定批注时优先选中普通正文。

### 8.2 添加、编辑与删除文字批注

1. 在选区或已有标记的工具栏中进入文字批注。
2. 输入自己的想法、问题或解释，提交保存。
3. 再次点击标记可以查看批注、修改颜色、编辑文字。
4. 通过删除操作和确认移除标记。

删除人工成果会同步移除原文上的高亮或批注，但不会删除被标记的原文。标记内容也可在阅读成果中心管理。

### 8.3 保存 AI 阅读成果

**入口：AI 回复附近 → 保存回复。**

1. 等待回复完成，将鼠标移到该回复附近。
2. 点击“保存回复”，选择摘要、问题集、AI 解读或阅读笔记。
3. 保存成功后，从右下角“阅读成果”入口回顾。
4. 如果希望得到独立文件，选择“Markdown”，再选择保存路径。

| 类型 | 适合保存什么 |
| --- | --- |
| 摘要 | 文档或章节的核心观点 |
| 问题集 | 复习题、自测题和待研究问题 |
| AI 解读 | 针对原文选区或来源的解释 |
| 阅读笔记 | 更自由的理解、推论和整理结果 |

保存通常收纳当前回复，不会仅因为选择“问题集”就重新生成一套题。需要特定内容时，先向 AI 提出对应要求，再保存结果。

AI 解读需要能够定位的本地来源；没有来源的普通回答可选择其他合适类型。保存结果可保留原问题、选区快照和参考资料；来源缺失的旧成果不一定有完整定位信息。

### 8.4 浏览、筛选与返回原文

**入口：右下角阅读成果图标；或 AI 面板顶部“阅读成果”。**

- **最近**：回顾近期记录，搜索成果或按类型缩小范围。
- **按文档**：先选择文档，再查看这篇文档关联的人工记录和 AI 成果。
- **独立成果**：没有可归属本地文档的记录可能在这里显示。
- 点击 AI 成果卡片展开，查看原问题、原始选区、AI 回复和参考资料。
- 点击“查看原文”返回相关文件或位置；联网来源可打开对应链接。
- 文档详情可按原文位置或时间查看，以界面提供的排序项为准。

“候选资料”不等于 AI 已在回答中引用的资料，注意卡片中的引用标识。来源文件不可用或原文变化时，会提示不可用或定位可能偏移；已保存成果正文仍可阅读，不应据此假定原文未变。

<a id="artifact-organization"></a>

### 8.5 收藏和分类

1. 在成果卡片的操作菜单中收藏或取消收藏。
2. 选择“设置分类”，勾选一个或多个分类，点击“完成”保存。
3. 在分类选择区输入名称，可新建分类。
4. 使用成果列表的收藏筛选和分类筛选，查看仅收藏、指定分类或未分类记录。
5. 在“分类 → 管理分类…”中重命名或删除分类。

分类名称为 1–40 个字符，不允许重名。分类组织的是已有成果，不会复制内容。

**删除分类仅解除归属，保留成果、收藏状态和原文。** 删除一条 AI 成果则移除这条成果及其整理记录；若它关联多篇文档，各文档入口中的同一条成果也会消失。

## 9. AI 助手

### 9.1 配置对话模型

**入口：设置 → AI 模型 → 对话 API 配置。**

1. 协议选择 **OpenAI Chat Completions**。
2. 选择服务预设，或填写供应商提供的 OpenAI-compatible API Base URL。
3. 在线服务填写 API Key；不需要鉴权的本地服务可以留空。
4. 填写服务实际提供的对话模型名称，或使用界面的模型列表／连接测试。
5. 发送一个简单问题确认配置可用，再尝试文档任务。

当前原生 **Anthropic Messages** 和 **OpenAI Responses** 尚未实现。使用相关供应商时，需要其提供的 OpenAI-compatible 接口；不能仅通过更换协议名称获得支持。

本地模型也需要先启动对应服务，并使用它提供的兼容接口和实际模型名。例如 Ollama 可使用 OpenAI-compatible 地址，具体端口以本机配置为准。

对话服务与 Embedding 服务可以来自不同供应商。模型是否支持工具调用会影响 Agent 任务，基础回答正常不代表所有工具任务都可执行。

### 9.2 API 地址授权和密钥

桌面版第一次请求自定义 API 或本地模型地址时，可能出现地址授权确认：

1. 核对目标地址是否就是你配置的服务。
2. 按提示选择本次或永久授权。
3. 永久授权可在“设置 → AI 模型 → API 地址授权”撤销。
4. 撤销后，再次访问可能要求重新授权。

桌面 API Key 通过 Windows 系统加密保存。已经保存的密钥显示固定掩码，不能读取、查看或复制原值；输入新 Key 会替换，清空输入会删除该连接的 Key。输入停顿或失焦后保存，按界面状态确认。

对话、Embedding、搜索密钥分别绑定到各自连接。切换地址或协议后，不能假定旧 Key 自动用于新地址；需要为新目标重新配置。普通数据备份不包含这些密钥。

<a id="web-keys"></a>

### 9.3 网页版 API Key

**入口：设置 → AI 模型，顶部密钥保存方式。**

| 方式 | 使用方法与影响 |
| --- | --- |
| 仅当前页面内存 | 默认方式；刷新或关闭后需要重新填写 |
| 明文 LocalStorage | 经过风险确认后保存；同源脚本可读取，建议只用可随时撤销的低额度 Key |
| 密码加密 LocalStorage | 使用同一个本地密码保存对话和搜索 Key；重新打开页面后输入密码解锁 |

在下方对话 API／搜索 API 区域填写 Key，再按密钥区域提示保存。密码加密方式不保存密码或解锁后的明文 Key，忘记密码不能从密文恢复原值；可清除保存的 Key 后重新配置。

加密保护的是浏览器里的保存数据，不能消除页面运行时恶意脚本读取或使用密钥的风险。供应商消费上限需要在供应商后台设置。

网页 AI 请求仍受 CORS 限制；地址正确但连接失败时，可能是服务没有允许网页所在域名访问。网页不提供桌面的永久 API 地址授权管理。

### 9.4 普通提问、停止与深度思考

点击右下角“AI”或按 Ctrl + J 打开面板。输入问题后按 Enter 发送，Shift + Enter 换行。生成过程中点击“停止生成”取消等待；失败时按提示检查配置，也可使用“重试”。

“深度思考”是输入区可切换的任务选项。是否使用更复杂的执行流程以及回答效果，仍取决于任务和模型能力，不代表每个模型都有相同的原生推理功能。

普通问题可以直接发送。观墨结合问题中的动作、资料来源、上下文标签和上轮任务，选择直接回答或 Agent 流程；并非出现一个关键词就一定调用工具。执行时间线可帮助判断正在读取、检索、搜索还是生成，具体提问示例见[按目的提问](#ai-question-examples)。

<a id="ai-context"></a>

### 9.5 添加选区或文件上下文标签

| 想提供的资料 | 推荐操作 |
| --- | --- |
| 一段文字 | 在源码或预览选中后，右键 → 添加到 AI 上下文 |
| 一篇文件 | 标签／文件右键 → 添加文件到 AI 上下文 |
| 一篇文件的总结 | 文件或标签右键 → AI 总结该文件 |
| 选区前后文 | 添加选区后，在问题中写“结合前后文解释” |

输入框上方出现标签后，再检查资料是否正确。不需要的上下文标签可以移除；移除标签不删除磁盘文件或已保存成果。

文件标签表示本轮指定的资料，不保证长文全文一次性发送。选区上下文优先读取相关片段；若信息不足，可以缩小问题范围或提供更明确的文件。

对话中的“这篇文章”“这个文件”不应替代明确的上下文选择。打开某个标签页也不意味着每次提问自动发送整篇文档。网页版保留基础聊天与用户主动提供的上下文，但不提供桌面数据库、知识库与长期记忆能力。

### 9.6 让 AI 修改文档

**适用流程：本轮提供单个选区或文件目标，生成确认卡，用户确认后应用。**

1. 选中需要修改的文字并添加选区标签，或添加目标文件标签。
2. 本轮仅保留一个修改目标，写清要求，例如“把这个选区改写得更简洁，保留所有事实”。
3. AI 生成“文件修改确认”卡片。
4. 检查文件名、变更摘要，展开“查看变更详情”。
5. 点击“确认应用”才会修改；不满意时点击“拒绝”。
6. 检查文档，再按保存规则保存到磁盘。

不要把确认卡中的短预览当成完整审校，必要时回到文档或 Diff 检查。没有本轮目标、目标有歧义或内容已变化时，软件可能拒绝应用；重新选择当前文本后再提出请求。

应用后可以点击“生成撤销确认卡片”，核对反向变更并再次确认。它是新的确认操作，不是按钮点击后立即无条件回退。历史消息中的待确认修改不一定能直接继续执行。

仅要求“翻译选区”会返回译文，不会自动替换。需要写回时明确要求“翻译并替换原文”，继续按修改确认流程处理。

### 9.7 快捷 AI 与行动确认

源码或预览选区右键提供快捷 AI 操作。它们来自“设置 → 快捷操作”，并受“快捷 AI 自动发送”控制：

- 开启：点击快捷操作后直接发送。
- 关闭：先填入输入框，由你检查后发送。

当 AI 提出保存成果、新建 Markdown 笔记、保存记忆或创建提醒时，可能显示独立的行动确认卡。核对内容后点击“确认执行”，或拒绝提案。AI 文字说“已整理好”不等于文件或数据已经保存，查看实际确认状态和成功提示。

### 9.8 保存回答和管理聊天历史

- 在回复附近“保存回复 → Markdown”可另存为文件。
- 保存为摘要、问题集、AI 解读、阅读笔记，见[阅读成果](#artifacts)。
- 桌面面板支持加载较早的历史问答；历史记录入口可在顶部或列表底部出现。
- “清空对话”清理当前面板对话，与删除数据库历史不同。
- 历史分组的“删除这组历史会话”在确认后删除该组持久记录。
- “设置 → 通用 → 数据管理 → 清空已保存会话”会清空全部已保存会话，操作不可恢复。

删除聊天历史不等于删除已独立保存的阅读成果。网页版不保留跨刷新聊天历史，需要主动另存有用内容。

### 9.9 联网搜索

1. 在“设置 → AI 模型 → 对话参数”开启“联网搜索”。
2. 在“Web 搜索”选择 Tavily、Serper、Brave Search 或自定义服务。
3. 填写该搜索服务的 Key 或完整搜索地址，并使用连接测试检查。
4. 在问题中明确要求“联网搜索”，写清要查的主题。
5. 回答出现网络来源时，点击链接核对原始资料。

对话 API Key 不等于搜索服务 Key。搜索服务、网络条件、浏览器跨域策略会影响结果；关闭联网搜索后，AI 普通知识回答不能当作已查询最新资料。

### 9.10 按目的提问：操作、关键词和例子

下面整合了仓库 [AI 使用指南](./AI_ROUTING_GUIDE.md) 的提问方法，并按当前能力补充示例。优先写清“要做什么、依据什么资料、希望得到什么结果”；关键词用于表达意图，不是强制调用工具的命令。

涉及知识库、长期记忆、阅读成果和提醒的示例适用于桌面版，并需先完成相应配置。联网搜索需要开启并配置搜索服务。

| 目的 | 操作或推荐表达 | 示例 |
| --- | --- | --- |
| 普通问答 | 直接提问 | 用两句话解释 Markdown 是什么。 |
| 指定文件总结 | 添加文件标签，或使用“AI 总结该文件” | 根据我添加的文件，总结核心内容、待办和风险。 |
| 总结或解释选区 | 添加选区标签 | 提炼这个选区的三个核心观点。 |
| 只翻译选区 | 添加选区标签，明确只要译文 | 把这个选区翻译成中文，只输出译文。 |
| 阅读选区附近内容 | 添加选区标签；写“结合上下文”“前后文” | 结合前后文，解释这段结论为什么成立。 |
| 阅读标题对应章节 | 选中标题并添加选区标签；写“本节”“标题下” | 总结这个标题下的本节内容，不扩展到整篇文档。 |
| 修改文档或选区 | 添加目标标签；写“改写”“润色”“替换” | 把这个选区改写得更简洁，保留原意。 |
| 翻译并写回 | 添加目标标签，明确替换原文 | 把这个选区翻译成中文，并替换原文。 |
| 检索本地知识库 | 写“知识库”“本地文档”“笔记库”“检索” | 检索本地知识库，查找自动保存的相关约定，并列出来源。 |
| 本地资料研究 | 写清主题和本地资料范围 | 基于我的笔记，梳理项目备份方案的共同点和分歧。 |
| 查找已保存阅读成果 | 写“搜索阅读成果”“高亮”“批注”“阅读笔记” | 搜索阅读成果，找出我关于备份的批注和阅读笔记。 |
| 查询长期记忆 | 写“查询我的记忆”“我的偏好” | 查询我的长期记忆，我偏好的回答格式是什么？ |
| 保存长期记忆 | 写“请记住”“保存到长期记忆” | 请记住：我偏好先给结论，再解释原因。 |
| 沿用个人风格 | 写“按我之前的风格”“按我的偏好” | 按我之前的写作风格润色这个选区。 |
| 联网搜索 | 写“联网搜索”“网上搜索”“最新资料” | 联网搜索这个主题的最新官方资料，并列出来源链接。 |
| 对照本地与网络资料 | 明确同时需要本地资料和联网核对 | 对照本地知识库和最新官网资料，判断这条配置是否过时。 |
| 查询当前时间 | 写“当前时间”“今天日期”“星期几” | 今天是几号，星期几？ |
| 保存 AI 阅读成果 | 明确成果类型和要保存的内容 | 把这段回答保存为阅读笔记。 |
| 新建 Markdown 笔记 | 明确要求新建 Markdown 文件 | 根据刚才的结论，新建一篇 Markdown 阅读笔记。 |
| 创建一次性阅读提醒 | 给出明确未来时间和事项 | 明天晚上八点提醒我复习这篇文档。 |

总结、解释和翻译通常只产生回答。改写文档、保存记忆、保存成果、新建笔记和创建提醒属于写入或行动，仍需对应授权与确认，不能靠关键词跳过。

<a id="ai-reading-scope"></a>

### 9.11 AI 如何选择资料范围

- **简单选区问题**：优先处理已提供的选区；“总结”“解释”“翻译”不会一律扩大为全文检索。只翻译不生成替换确认卡。
- **依赖上下文的问题**：例如“为什么成立”“与前文有什么关系”，可能读取选区附近的相关内容。读取范围有限，不代表读取整篇。
- **标题章节问题**：选中标题后要求阅读“本节”，以标题所属章节为范围，在下一个同级或更高级标题前停止；返回内容仍可能受长度限制。
- **指定文件总结**：需要文件标签，优先读取这篇已授权文件。内容截断或读取不足时，应说明总结基于已读取范围，不能声称覆盖全文。
- **本地研究**：明确主题研究或知识库问题可检索已入库资料，不要求先添加文件标签；本地研究本身不代表已经联网搜索。
- **本地与网络对照**：明确要求联网核对时，区分两类来源；搜索关闭、失败或没有结果时，应说明外部对照没有完成。
- **阅读成果回顾**：检索的是已经保存的高亮、批注或 AI 成果，与读取磁盘原文、检索知识库是不同能力。
- **个人风格**：要求沿用既有风格、语气或格式时，可检索相关偏好和指令记忆；普通改写不必检索个人记忆。

普通无来源回答不会强行展示来源。研究或复杂问题可能按结论、依据、来源、推断和信息不足组织回答；简单问答无需固定套用研究报告结构。

要判断用了哪些资料，请查看执行时间线与实际来源。添加标签、得到回答、生成确认卡、应用修改、保存到磁盘，是不同阶段。

<a id="ai-continuation"></a>

### 9.12 连续任务：继续、重试与换方法

当前对话保留上轮 Agent 任务上下文时，以下独立短指令可以续接原任务，并沿用原任务的能力范围：

- 重试：再试、再试试、再试一次、再来一次、重试、重新、重新来、重新试、重新试一次、retry。
- 继续：继续、继续一下、继续吧、继续找、继续搜索、continue。
- 换方法或补充尝试：换一个、换个方法、换一种方法、刚才那个、还是不行、再找找、再搜搜。

例如，上轮已检索本地知识库，随后发送“继续找”，会续接该检索任务；上轮联网搜索失败，发送“再试一次”，会尝试沿用原搜索任务。续接并不保证成功，也不代表解除服务配置、权限或请求限制。

这是有上轮任务上下文时的续接，不是所有普通聊天或历史会话都能自动续接。上述表达需作为独立短指令；如果改变目标，直接写清新的任务和资料范围。

续接不继承新的文档修改授权。再次要求修改原文时，仍需本轮目标标签和确认；保存成果、记忆或提醒仍要确认。清空对话后，重新说明任务，不要只写“继续”。

<a id="knowledge-memory"></a>

## 10. 本地知识库与长期记忆

**适用环境：桌面版。使用在线模型时，相应对话、检索片段或 Embedding 文本会发送给你配置的服务；本地保存数据不等于所有处理都离线。**

### 10.1 配置 Embedding 和入库

1. 打开“设置 → AI 模型 → Embedding 配置”。
2. 配置 OpenAI Embeddings 兼容服务地址、Key 和 Embedding 模型。
3. 在“知识库”区域选择是否开启“自动入库”。
4. 开启后，打开或保存 Markdown 会触发入库；关闭后，右键标签或文件选择“加入知识库”。
5. 已入库文件的对应菜单会显示“已加入知识库（点击更新）”。

打开一个工作区不等于其中全部文档已建立索引。要批量处理当前工作区，可使用“重建当前工作区”，见下一节；它可能重新调用 Embedding 服务。完成后在知识库状态或管理列表中确认实际入库结果。

自动入库、语义分块、生成向量是相关但不同的步骤。新增或修改后需要等待队列处理，不能把“已打开文件”当成“已经完成全部嵌入”。

### 10.2 查看状态与处理队列

“设置 → AI 模型 → 知识库”显示文档、分块、已嵌入、待嵌入数量，以及自动队列状态。

| 状态／操作 | 含义 |
| --- | --- |
| PENDING | 等待处理 |
| CHUNKED | 已分块，尚未完成全部后续处理 |
| EMBEDDING | 正在生成向量 |
| INDEXED | 已完成索引 |
| FAILED | 处理失败，需要查看配置或重试 |
| 处理嵌入队列 | 处理待嵌入内容 |
| 重试失败 | 重新处理失败任务 |
| 刷新统计 | 更新界面数量 |
| 管理文档 | 搜索和检查已入库文档 |
| 清理失效索引 | 清理失效来源对应的索引 |
| 重建当前工作区 | 按当前工作区重建索引，可能重新调用 Embedding 服务 |

在线 Embedding 可能产生服务费用。换模型、重建或重复处理前，先确认服务配置和使用额度。

### 10.3 检索自己的文档

可以不添加文件标签，直接问：

> 检索本地知识库，找出关于项目备份的约定，并列出来源。

知识库搜索的是已入库资料，不会扫描电脑所有文件。回答返回相关片段和来源，点击本地来源可尝试打开对应文档或行。

完整总结指定文章时，优先添加文件标签；知识库命中几个片段，不代表已经读完全文。无结果时检查入库、分块和队列状态，尝试更具体的关键词。

### 10.4 从知识库移除文档

在“知识库 → 管理文档”按文件名搜索，选择文档后使用移除或批量移除。

移除仅删除知识库索引／分块数据，**不删除本地 Markdown 文件**。自动入库开启时，后续再次打开或保存该文件可能重新入库；希望暂停自动加入时先关闭自动入库。

### 10.5 添加和确认长期记忆

**入口：设置 → 记忆。**

- 点击“添加记忆”，填写内容，选择作用域和类型后保存。
- 也可在 AI 对话中明确说“请记住：我偏好先给结论”，按提案或候选记忆的确认流程保存。
- 候选区点击“确认保存”才会成为正式记忆；不需要的候选可忽略。
- 不能仅凭 AI 回复“我记住了”判断持久记忆已写入，应检查设置中的正式记录。

记忆适合稳定的偏好、约定和背景，不适合把整篇资料当作全文知识库使用。

### 10.6 作用域、类型、锁定与归档

| 操作 | 用途与影响 |
| --- | --- |
| 全局记忆 | 可用于不同项目的稳定偏好或背景 |
| 项目记忆 | 关联当前工作区，避免把某个项目约定套到另一个项目 |
| 按作用域／类型筛选 | 查找当前范围内的记忆 |
| 锁定／解锁 | 保护重要记忆，避免自动整理随意改动 |
| 归档 | 停止作为当前有效记忆使用，与直接删除不同 |
| 删除 | 移除该记忆，谨慎确认 |
| 清空候选记忆 | 批量清除待确认候选，不等于清空所有正式记忆 |

普通改写不会必然检索个人记忆。希望沿用既有风格时明确写“按我的既有写作风格改写”，希望查询记录时明确写“查询我的长期记忆”。

### 10.7 阅读提醒（试用）

当前桌面界面仍标注“阅读提醒（功能开发中）”，但已提供一次性提醒的提案、确认和管理入口。

1. 在 AI 对话中提出明确的未来时间，例如“明天晚上八点提醒我复习这篇文档”。
2. 检查确认卡中的标题、内容和时间，确认后才注册。
3. 在 AI 面板顶部“阅读提醒”查看状态。
4. 未到期且允许编辑的提醒可“改期”；待处理提醒可“取消”，失败时可“重试”，也可删除记录。

这是一次性提醒，不应当作定时重复任务工具。确认提案不等于已验证系统一定弹出通知；系统通知权限、设备状态和当前功能成熟度会影响实际送达。本次没有验证应用退出后或设备休眠时的通知送达。

### 11.1 系统主题与自定义主题

**入口：设置 → 通用 → 外观。**

暖色、浅色和深色主题会应用到软件界面、编辑器和预览。主题选择不改变 Markdown 内容。

桌面自定义主题流程：

1. 点击“添加主题”。
2. 复制主题生成提示词，交给 AI 描述希望的风格。
3. 取得完整 JSON，粘贴到导入区域，按提示校验并导入。
4. 选择导入后的主题卡片使用。

前三个系统主题不能删除，后两个槽位用于自定义主题；槽位满时先删除不需要的自定义主题，再导入。JSON 字段不完整、颜色格式错误或重名时可能被拒绝，不能只粘贴 AI 对主题的文字描述。

### 11.2 字体、显示与编辑行为

| 设置 | 使用说明 |
| --- | --- |
| 字号／行高 | 编辑器页调整正文尺寸与间距；Ctrl + 鼠标滚轮可快捷调整字号 |
| AI 助手内容字号 | 通用页调整聊天、阅读成果、提醒和输入框的字号 |
| Tab 大小 | 调整缩进空格数 |
| 自动换行 | 控制长源码行是否折行，不插入实际换行字符 |
| 行号 | 控制编辑器是否显示行号 |
| 同步滚动 | 分屏时联动源码与预览 |
| 预览内源码编辑 | 开启后可 Alt + 点击编辑块 |
| 默认打开模式 | 桌面通过文件关联冷启动时选择编辑或预览；应用已启动时不强制改当前模式 |
| 快捷 AI 自动发送 | 控制选区快捷操作立即发送还是先填入输入框 |
| 自动保存 | 桌面已有路径文档可用；网页版不可用 |

定制光标、AI 头像和状态预览位于“通用 → 外观”。调整 AI 头像不改变模型或任务能力。

### 11.3 模式性能策略

**入口：设置 → 编辑器 → 性能 → 模式性能策略。**

- **节省内存**：减少隐藏模式保留和闲时预热。
- **平衡**：在资源占用和切换体验之间折中。
- **极速切换**：更积极地预热和保留当前文档的编辑／预览资源，可能使用更多内存。

这些策略调整资源使用方式，不改变文档内容。选择后按自己的文档和设备观察；不能将某个策略理解为所有场景都会更快或占用固定内存。

### 11.4 自定义快捷 AI 操作

1. 进入“设置 → 快捷操作”，点击“新增操作”。
2. 填写显示名称和希望 AI 处理当前选区的提示词。
3. 保存后，在源码或预览选区右键菜单中使用。
4. 列表中可编辑、删除、调整顺序和启用状态。
5. “恢复默认”会覆盖当前自定义快捷操作，先保存需要保留的提示词。

快捷操作沿用正常 AI 路由、当前上下文和修改确认规则。自定义一个叫“直接替换”的操作，不会绕过文件修改确认。

### 11.5 AI 参数、请求超时与提示词

- **AI 创造性**：较低值偏稳定，较高值偏发散，实际效果取决于模型。
- **流式输出**：控制回复是否边生成边显示。
- **用户偏好提示词**：描述语言、篇幅和结构，例如“优先用中文，先给结论，使用简短段落”。
- **高级设置 → 请求超时**：分别在对应服务配置区域调整等待时长；慢模型或网络不稳定时可按实际需要调整。

偏好提示词不覆盖工具、文件、记忆和行动确认规则。增加超时不能修复地址错误、无效 Key 或跨域拒绝。

### 11.6 动效与使用统计

“通用 → 动效”可调整全屏过渡、全屏选项展开和发送消息动画。系统开启“减少动态效果”时相关动画会受限制；滚动消息列表会结束发送消息动画。

桌面“通用 → 使用统计”可查看累计时长和按日期的记录，使用“记录”开关控制统计，点击“刷新”更新显示。统计按窗口活动状态计算，不等于从启动到退出的全部自然时间。

“清空使用数据”需要确认，清空后从当前时刻重新统计，不能恢复旧时长。它不删除文档、对话或阅读成果。

### 11.7 恢复默认设置

**入口：设置 → 通用 → 恢复默认设置。**

该操作会重置对话／Embedding 地址和模型、部分 AI 参数、搜索配置、编辑器显示与行为、主题与动效、使用统计开关和自定义快捷操作。执行前记录需要保留的地址、模型和提示词。

恢复默认不是数据备份恢复，也不用于清空文档、阅读成果或长期记忆。它不是“彻底删除所有密钥”的入口；要删除 Key，请到对应连接控件明确删除。恢复后可能需要重新选择或填写服务配置。

## 12. 数据、备份与维护

### 12.1 哪些数据保存在哪里

| 数据 | 保存方式与迁移要求 |
| --- | --- |
| Markdown 原文 | 保存到你选择的磁盘位置，软件升级不等于文档备份 |
| 文档本地图片 | 通常在文档同级 assets 目录，随文档一起备份 |
| 桌面会话、消息、长期记忆、批注、阅读成果及整理信息 | 应用本地数据库，通过普通数据备份迁移 |
| 知识库索引与向量 | 本地派生数据，普通备份不包含，可重新入库和生成 |
| 对话、Embedding、搜索 Key | 桌面系统加密保存，普通备份不包含 |
| 主题、界面设置、工作区授权、背景库、使用统计、诊断日志 | 独立于普通业务备份，不应假定已包含在备份 JSON 中 |
| 网页文件、标签和聊天 | 页面会话内，刷新不恢复；密钥按选择方式单独处理 |

使用在线 AI、Embedding 或搜索服务时，必要的请求内容会发送到你配置的服务。使用本地模型可减少对应外部处理，但仍需区分是否开启联网搜索、远程图片或其他联网功能。

备份 JSON 可能含聊天、记忆、原始选区、成果和来源路径等私人资料。不要因为不含 API Key 就把它当作可以公开分享的文件。

<a id="backup"></a>

### 12.2 导出备份

**适用环境：桌面版。入口：设置 → 通用 → 数据管理 → 导出备份。**

1. 选择保存位置，导出 JSON 文件。
2. 查看成功提示，保留备份文件。
3. 另外备份本地 .md 文档及其 assets 目录。

当前普通备份包含：

- 聊天会话及消息。
- 长期记忆和候选记录。
- AI 阅读成果。
- 人工高亮与文字批注。
- 成果分类及收藏／分类归属。
- 已保存的阅读提醒记录。

**不包含** API Key、Markdown 磁盘文件、图片文件、知识库索引与向量，也不是主题、全部设置或整个应用目录的镜像。

### 12.3 导入与迁移到新设备

1. 在原设备导出普通备份，并单独复制 Markdown 和图片。
2. 在新设备安装观墨，先打开需要使用的文档或工作区，建立访问权限。
3. 进入“设置 → 通用 → 数据管理 → 导入备份”，选择原备份 JSON。
4. 确认导入成功，检查会话、记忆、标记和阅读成果。
5. 重新配置模型 Key 与地址；需要知识库时重新入库并处理嵌入队列。

导入会合并／恢复备份中的记录，不是无条件替换所有本机状态，也不是文件内容回滚。建议先备份当前设备的数据再导入。

同名成果分类会优先复用本地分类，分类映射与其他记录一起处理。旧备份可能没有批注或分类等新增字段，缺失部分按兼容规则处理；不能从旧备份恢复本来未导出的信息。

无效或不支持的备份会拒绝导入；导入失败时事务回滚。不要自行修改 JSON 版本号强行导入。

来源路径保存在记录中。迁移后文档路径改变时，已保存内容可保留，但原文跳转可能失效；普通备份不会自动重新映射所有旧路径，也不会重新授予文件权限。

### 12.4 旧版数据库检测

**入口：设置 → 通用 → 旧版数据迁移 → 检测旧数据。**

当前界面检测旧版 IndexedDB 数据，并在发现时提供“下载迁移工具”入口，按工具说明处理。

它不是当前界面中的一键自动迁移按钮。旧数据库与当前数据库可能同时存在，先保留原数据和备份；不要通过删除数据库或清空应用目录解决迁移问题。

### 12.5 检查更新

**入口：桌面设置 → 通用 → 关于 → 检查更新。**

检查发现新版本后，可打开下载页。当前更新机制提供检查和下载入口，不会自动安装。

安装更新前保存文档；有重要数据时先导出备份。启动时的静默检查与手动检查不同，想主动确认时使用“检查更新”。

### 12.6 诊断日志与反馈

**入口：桌面设置 → 诊断。**

- **详细诊断模式**：默认关闭；开启后额外记录慢路径，设置会保留到下次启动。
- **导出 diagnostics zip**：选择位置导出诊断包，用于排查启动、耗时和关键故障。
- **打开日志目录**：查看应用的诊断文件。
- **清除日志**：确认后只删除指定的轮转诊断日志，不删除设置或业务数据。

诊断日志记录固定状态、耗时和数量，不记录文档正文、AI 对话正文、API Key 或完整文件路径。轮转日志按容量和保留时间清理，重要故障出现后及时导出。

向项目反馈时可提供软件版本、桌面／网页环境、操作入口、最短复现步骤、错误提示和诊断包。不要附上真实密钥；自行提供的截图、错误文字或备份也需要检查私人内容。

### 12.7 删除操作影响速查

| 操作 | 实际影响 |
| --- | --- |
| 关闭标签 | 移除当前标签；不删除磁盘文件，未保存内容需先处理 |
| 关闭工作区 | 移除工作区入口，不删除目录 |
| 删除最近记录、取消文件收藏 | 移除入口或收藏关系，不删除原文 |
| 移除知识库文档 | 删除索引／分块，不删除磁盘原文 |
| 删除人工高亮或批注 | 同步移除标记和人工成果，不删除原文 |
| 删除 AI 阅读成果 | 移除该条成果及关联整理记录，不改原文 |
| 删除成果分类 | 解除分类归属，保留成果与收藏 |
| 清空当前对话 | 清理面板对话，不等于清空数据库历史 |
| 删除历史分组／清空已保存会话 | 删除相应持久会话，不能靠刷新恢复 |
| 清空候选记忆 | 清除待确认候选，不等于删除所有正式记忆 |
| 删除个人背景 | 删除背景库副本，不删除原始导入图片 |
| 清空使用数据 | 清除使用时长记录 |
| 清除诊断日志 | 清除指定诊断文件，不删除业务数据 |
| 恢复默认设置 | 重置相关配置，不恢复文件，也不是普通数据清空 |

## 14. 常见问题

### 14.1 找不到某个按钮

先确认桌面还是网页、软件版本、当前是否全屏，以及侧栏／AI 面板是否收起。全屏按钮在屏幕顶部控制条，普通 AI 和阅读成果入口在右下角。设置通过 Ctrl + I 打开。

### 14.2 文件打不开或出现权限提示

检查是否为 .md、是否超过 1 MiB、文件是否仍存在和磁盘是否可访问。用“打开文件”重新选择该文件，或通过“打开文件夹”选择工作区。

仅粘贴路径或让 AI 知道路径，不会授予磁盘访问权限。不要通过移动整个应用数据目录或删除授权记录尝试绕过。

### 14.3 自动保存开了，为什么仍有“已修改”

新文档需要先选择保存路径；已有文件可能仍在保存中或保存失败。查看提示并按 Ctrl + S，确认修改标记消失。网页版不提供自动保存，需要主动保存或下载。

### 14.4 最近文件、收藏或成果无法返回原文

文件可能移动、删除、权限失效或内容发生较大变化。先重新打开实际文件，再检查旧入口。成果正文与来源定位是不同数据，定位失败不等于成果内容已丢失。

### 14.5 网页刷新后文档和聊天没了

网页不恢复文件、标签和聊天，这是能力范围。刷新前下载文档、另存 AI 回复；如果需要长期记录、批注或备份，请使用桌面版。保存 API Key 不会同时保存会话。

### 14.6 AI 连接失败

按顺序检查：地址是否为兼容接口、模型名是否有效、Key 是否配置到当前连接、本地服务是否启动、桌面地址授权是否通过、服务是否限额。

网页还需检查 CORS；网络搜索需单独检查搜索 Key。报“请求限流”时稍后重试；报“当前会话上限”时不要持续重复请求。供应商用量上限与软件本地请求限制不同。

### 14.7 AI 不知道我正在看的文档

先添加选区或文件到 AI 上下文，确认输入框出现正确标签，再提出问题。跨文档研究可明确要求检索本地知识库，但只检索已入库内容。

### 14.8 AI 给出改写，却没有修改文件

普通回复、译文或建议不会自动写回。提供本轮单个目标，明确要求修改，等待文件修改确认卡，再确认应用。确认后还需要按保存规则写入磁盘。

### 14.9 知识库没有结果或嵌入失败

检查是否桌面版、文档是否入库、Embedding 地址与模型是否正确，以及待处理／失败数量。先处理嵌入队列或重试失败，再检索；可换更具体的关键词。不要先删除全部索引或重建数据库。

### 14.10 预览内编辑无法开启或出现冲突

检查“预览内源码编辑”是否开启，按住 Alt 点击普通 Markdown 块。特殊渲染内容的命中方式可能不同。

出现冲突时先复制草稿，核对当前正文后重新编辑；提示冲突不表示草稿已经覆盖文档。

### 14.11 高亮或批注没有出现

确认是桌面版、数据库已就绪、文档已有本地保存路径，并在预览中选中普通原文。搜索高亮与临时选区不是保存的人工标记。源文件发生变化时，还需检查标记定位情况。

### 14.12 导出图片缺失或 PDF 没有生成

先确认预览中的图片路径可读、assets 文件仍存在，等待图表和字体加载完成。HTML 图片不可读时会取消导出；PDF 还需要你在打印对话框完成保存。

导出文件与 Markdown 原文不同，导出失败不会替代或完成原文保存。

### 14.13 保存后 Diff 仍显示变化

Diff 基线是打开文档时的内容，不是上次自动保存。保存只写回磁盘，不会让原始快照与当前内容自动相等。

### 14.14 备份导入后没有文档、图片或 API Key

普通备份包含应用业务记录，不包含磁盘文档、图片或 Key。需单独复制文档与资源，并重新配置服务、授权路径和重建知识库，见[备份恢复](#backup)。

### 14.15 提醒确认了，但没有系统通知

阅读提醒仍是试用功能。先看提醒列表的注册状态、时间和错误码，再检查系统通知设置；不要把确认卡成功当成已经验证通知送达。提供版本和诊断信息反馈，避免重复创建多条相同提醒。
