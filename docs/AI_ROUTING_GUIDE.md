# AI 使用指南

> 适用版本：观墨公开版 1.11.0。最后按仓库实现核对：2026-10-19。
>
> 本文用于查阅 AI 提问方式、资料范围和连续任务规则。模型配置、密钥管理及完整操作流程见 [观墨使用手册：AI 助手](./USER_GUIDE.md#ai)。

## 开始提问前

1. 在“设置 → AI 模型”配置对话服务、API Key 和模型，先用普通问题检查连接。
2. 要处理当前原文，选中文字后右键“添加到 AI 上下文”，或在文件／标签右键选择“添加文件到 AI 上下文”。确认输入框出现正确标签，再发送问题。
3. 联网搜索需要单独开启并配置搜索服务；知识库检索需要先入库，语义检索还需配置 Embedding。
4. 知识库、长期记忆、持久阅读成果和阅读提醒属于桌面能力。网页版保留基础 AI 对话和联网搜索，受浏览器跨域限制。

观墨结合问题中的动作、资料来源、上下文标签和上轮任务，选择直接回答或 Agent 流程。优先写清“要做什么、依据什么资料、希望得到什么结果”；关键词用于表达意图，不是强制调用工具的命令。

## 按目的提问

以下知识库、长期记忆、阅读成果和提醒示例适用于桌面版。阅读提醒当前仍标为开发中，按试用功能使用，不能仅凭确认卡成功判断系统通知已送达。

| 目的 | 操作或推荐表达 | 示例 |
| --- | --- | --- |
| 普通问答 | 直接提问 | 用两句话解释 Markdown 是什么。 |
| 指定文件总结 | 添加文件标签，或使用“AI 总结该文件” | 根据我添加的文件，总结核心内容、待办和风险。 |
| 总结或解释选区 | 添加选区标签 | 提炼这个选区的三个核心观点。 |
| 只翻译选区 | 添加选区标签，明确只要译文 | 把这个选区翻译成中文，只输出译文。 |
| 阅读选区附近内容 | 添加选区标签；写“结合上下文”“前后文” | 结合前后文，解释这段结论为什么成立。 |
| 阅读标题对应章节 | 选中标题并添加选区标签；写“本节”“标题下” | 总结这个标题下的本节内容，不扩展到整篇文档。 |
| 修改文档或选区 | 添加目标标签；写“改写”“润色”“替换” | 把这个选区改写得更简洁，保留原意。 |
| 翻译并写回 | 添加目标标签，明确替换原文 | 把这个选区翻译成中文，并替换原文。 |
| 检索本地知识库 | 写“知识库”“本地文档”“笔记库”“检索” | 检索本地知识库，查找自动保存的相关约定，并列出来源。 |
| 本地资料研究 | 写清主题和本地资料范围 | 基于我的笔记，梳理项目备份方案的共同点和分歧。 |
| 查找已保存阅读成果 | 写“搜索阅读成果”“高亮”“批注”“阅读笔记” | 搜索阅读成果，找出我关于备份的批注和阅读笔记。 |
| 查询长期记忆 | 写“查询我的记忆”“我的偏好” | 查询我的长期记忆，我偏好的回答格式是什么？ |
| 保存长期记忆 | 写“请记住”“保存到长期记忆” | 请记住：我偏好先给结论，再解释原因。 |
| 沿用个人风格 | 写“按我之前的风格”“按我的偏好” | 按我之前的写作风格润色这个选区。 |
| 联网搜索 | 写“联网搜索”“网上搜索”“最新资料” | 联网搜索这个主题的最新官方资料，并列出来源链接。 |
| 对照本地与网络资料 | 明确同时需要本地资料和联网核对 | 对照本地知识库和最新官网资料，判断这条配置是否过时。 |
| 查询当前时间 | 写“当前时间”“今天日期”“星期几” | 今天是几号，星期几？ |
| 保存 AI 阅读成果 | 明确成果类型和要保存的内容 | 把这段回答保存为阅读笔记。 |
| 新建 Markdown 笔记 | 明确要求新建 Markdown 文件 | 根据刚才的结论，新建一篇 Markdown 阅读笔记。 |
| 创建一次性阅读提醒 | 给出明确未来时间和事项 | 明天晚上八点提醒我复习这篇文档。 |

总结、解释和翻译通常只产生回答。改写文档、保存记忆、保存成果、新建笔记和创建提醒属于写入或行动，仍需对应授权与确认，不能靠关键词跳过。

文件修改需本轮提供单个明确目标，并在“文件修改确认”卡片中核对后确认应用；应用后还需按保存规则保存到磁盘。保存成果、记忆、新建笔记或创建提醒时，按行动提案或候选记录的实际确认流程处理。详见 [修改文档](./USER_GUIDE.md#ai) 和 [阅读成果](./USER_GUIDE.md#artifacts)。

## AI 如何选择资料范围

- **简单选区问题**：优先处理已提供的选区；“总结”“解释”“翻译”不会一律扩大为全文检索。只翻译不生成替换确认卡。
- **依赖上下文的问题**：例如“为什么成立”“与前文有什么关系”，可能读取选区附近的相关内容。读取范围有限，不代表读取整篇。
- **标题章节问题**：选中标题后要求阅读“本节”，以标题所属章节为范围，在下一个同级或更高级标题前停止；返回内容仍可能受长度限制。
- **指定文件总结**：需要文件标签，优先读取这篇已授权文件。内容截断或读取不足时，应说明总结基于已读取范围，不能声称覆盖全文。
- **本地研究**：明确主题研究或知识库问题可检索已入库资料，不要求先添加文件标签；本地研究本身不代表已经联网搜索。
- **本地与网络对照**：明确要求联网核对时，区分两类来源；搜索关闭、失败或没有结果时，应说明外部对照没有完成。
- **阅读成果回顾**：检索的是已经保存的高亮、批注或 AI 成果，与读取磁盘原文、检索知识库是不同能力。
- **个人风格**：要求沿用既有风格、语气或格式时，可检索相关偏好和指令记忆；普通改写不必检索个人记忆。

普通无来源回答不会强行展示来源。研究或复杂问题可能按结论、依据、来源、推断和信息不足组织回答；简单问答无需固定套用研究报告结构。

要判断用了哪些资料，请查看执行时间线与实际来源。添加标签、得到回答、生成确认卡、应用修改、保存到磁盘，是不同阶段。

## 连续任务路由继承

当前对话保留上轮 Agent 任务上下文时，以下独立短指令可以续接原任务，并沿用原任务的能力范围：

- 重试：再试、再试试、再试一次、再来一次、重试、重新、重新来、重新试、重新试一次、retry。
- 继续：继续、继续一下、继续吧、继续找、继续搜索、continue。
- 换方法或补充尝试：换一个、换个方法、换一种方法、刚才那个、还是不行、再找找、再搜搜。

例如，上轮已检索本地知识库，随后发送“继续找”，会续接该检索任务；上轮联网搜索失败，发送“再试一次”，会尝试沿用原搜索任务。续接并不保证成功，也不代表解除服务配置、权限或请求限制。

这是有上轮任务上下文时的续接，不是所有普通聊天或历史会话都能自动续接。上述表达需作为独立短指令；如果改变目标，直接写清新的任务和资料范围。

续接不继承新的文档修改授权。再次要求修改原文时，仍需本轮目标标签和确认；保存成果、记忆或提醒仍要确认。清空对话后，重新说明任务，不要只写“继续”。

## 排查和进一步阅读

- 不知道当前原文：先检查是否添加了正确的上下文标签，不要仅使用“这篇文章”代替指定资料。
- 知识库没有结果：检查是否入库、队列是否完成、Embedding 配置是否可用，再缩小问题范围。
- 联网对照未完成：检查搜索开关、搜索服务配置和实际来源；普通回答不能代替最新资料查询。
- 要保留回答：可在回复附近选择“保存回复”，另存 Markdown 或保存为对应阅读成果。
- 完整设置、历史会话、修改确认与密钥说明见 [使用手册](./USER_GUIDE.md#ai)，其他排查见 [常见问题](./USER_GUIDE.md#faq)。

本文与使用手册第 9.10–9.12 节的示例、资料范围和续接规则同步维护；功能行为以当前实现为准，不将计划中的能力写成现有用法。
