# 恢复 AI 解释选区输出

## Goal

恢复“AI 解释这段”在 `v1.2.1` 中按选区内容自然决定解释深度的行为，避免近期全局输出风格规则把解释强制压缩为一句话，同时保留现有安全、来源和编辑授权规则。

## Confirmed Facts

- 编辑器与预览菜单仍提交“请解释这段内容”，与 `v1.2.1` 一致。
- 该请求仍被 `selection_fast_path` 识别为快速路径，不进入 Agent、RAG 或全文读取。
- 当前未提交的 `BASE_SYSTEM_PROMPT` 新增“普通问答和简单解释”“能用一句话说清就不要分段”的约束，这是相对 `v1.2.1` 的直接行为差异。

## Requirements

- “AI 解释这段”必须继续只使用本轮 selection 内容并走快速回答路径。
- 解释深度应由选区复杂度决定；代码、公式、概念或因果关系需要时必须允许完整说明。
- 不强制一句话，也不强制标题、章节或固定模板。
- 普通问答仍可保持当前简洁策略。
- 不改变“结合上下文解释”、总结、翻译、改写、来源展示和文件修改确认流程。
- 不覆盖当前工作区已有未提交改动，不批量暂存无关文件。

## Acceptance Criteria

- [x] “请解释这段内容”在 selection 上下文中仍分类为 `fast`，候选 Agent 工具为空。
- [x] 系统提示词不再把“简单解释”纳入一句话压缩规则。
- [x] 系统提示词明确要求 selection 解释按内容复杂度完整说明且不套固定结构。
- [x] `npm run test:agent-parser` 通过。
- [x] `npm run build` 通过。
- [x] `git diff --check` 通过，且改动边界仅包含本任务必要行与 Trellis 任务工件。

## Out of Scope

- 不整体回退到 `v1.2.1`。
- 不调整模型参数、Agent 工具、RAG、长期记忆或 UI。
- 不为模型输出建立快照测试；验收聚焦可确定的路由和提示词契约。
